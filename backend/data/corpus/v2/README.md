# Corpus documental v2

Siete manuales PDF simulados de AulaTI, versión 2.0. `manifest.json` es la lista
exclusiva de fuentes recuperables y registra sus SHA-256, categoría, versión e
identificador. La ingestión verifica cada hash y conserva sección y página.

Estos archivos provienen de `manuals/TI-support-RAG_Manuales_PDF.zip` y mantienen
sus bytes originales. `manuals/` conserva el paquete y la organización previa;
la ingestión utiliza únicamente las rutas de este manifiesto en `data/corpus/v2/`.
No se indexan ambos directorios ni se ingieren este README, el manifiesto, el ZIP
o las preguntas de evaluación como documentos.

Para una nueva versión, conservar originales y crear un manifiesto/construcción
distintos. Ningún procedimiento aquí representa una política institucional real.
